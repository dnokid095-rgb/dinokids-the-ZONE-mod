DINOKID509S ZONE MOD (Fabric 1.21.11)

HOTKEYS (rebindable in Controls > Key Binds > dinokid509s Zone mod)
  Z toggle | X cycle mode | ] intensity up | [ intensity down

BUILD WITHOUT INSTALLING ANYTHING: upload to a GitHub repo, the included
workflow (.github/workflows/build.yml) builds the jar under Actions > Artifacts.
LOCAL BUILD: JDK 21 + Gradle 9.2.1, run:  gradle build   (jar in build/libs, not -sources)
Needs Fabric API in the mods folder.
